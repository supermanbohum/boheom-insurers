# 광고 교체 방법

1. 광고 이미지를 이 `ads/` 폴더에 올린다 (권장 크기 690×360px, png/jpg, 300KB 이하)
2. `ads.json`을 열어 left(왼쪽 5) / right(오른쪽 5) / top(메인 상단 5) / bottom(메인 하단 5) 배열에 한 줄 추가:
   {"img":"ads/파일명.png","url":"https://클릭시이동주소","alt":"광고 설명"}
3. 위에서부터 순서대로 각 구역 1~5번 칸에 들어간다. 5개 넘는 건 무시됨. 비어 있는 칸은 "광고 N · 광고문의"로 표시.
4. `contact` 값이 빈 칸에 표시되는 광고문의 문구.
5. 저장(커밋)하면 1분 안에 사이트에 반영.
